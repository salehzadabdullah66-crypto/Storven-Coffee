# مقهى ستورفين كوفي | Storven Coffee ☕
موقع ويب تعريفي وتسويقي فخم واحترافي لمقهى القهوة المختصة **"Storven Coffee" (ستورفين كوفي)** الواقع قرب أوتوستراد إدلب.

---

## 🌟 المميزات والمواصفات المنجزة

1. **الهوية البصرية الفاخرة**:
   - الألوان الرسمية: أخضر داكن فخم (`#0F2A1D`)، أخضر متوسط (`#1F5A3D`)، ذهبي ملكي (`#C9A55C`)، بيج كريمي دافئ (`#F5F0E6`)، وأخضر واتساب التفاعلي (`#25D366`).
   - خطوط Google Fonts عربية أصيلة (`Cairo` & `Tajawal`) مع خط براند لاتيني كلاسيكي (`Playfair Display`).
   - زوايا مستديرة كبيرة (20–28px)، ظلال ناعمة وتدرجات راقية.

2. **التفاعل وتعدد اللغات والثيم**:
   - تبديل فوري بين اللغتين **العربية والإنجليزية (AR / EN)** مع التبديل التلقائي لاتجاه الصفحة (`RTL` / `LTR`).
   - تبديل سلس بين **الوضع الليلي والنهاري (Dark / Light Mode)** مع حفظ خيار الزائر في المتصفح (`localStorage`).
   - شاشة تحميل أولية أنيقة (Preloader) بحركة فنجان وبخار قهوة متحرك.

3. **الأقسام التفاعلية**:
   - **الهيدر الثابت (Sticky Glassmorphism)**: شعار دائري ذهبي، قائمة تنقل سلسة، أزرار اللغة والثيم، وقائمة للموبايل.
   - **لحظات ستورفين (Storven Moments - Stories)**: شريط قصص مثل إنستغرام بحدود ذهبية مشعة يفتح مشغل ستوري عمودي متكامل مع شريط تقدم زمني، تنقل باللمس والسحب، وتحكم كامل.
   - **الهيرو (Hero)**: خلفية قهوة سينمائية، شعار ضخم، أزرار دعوة لاتخاذ إجراء (CTA)، وإحصائيات سريعة.
   - **قصتنا (About)**: تخطيط عمودين مع شارة عائمة و4 بطاقات مزايا (حبوب مختارة، أجواء دافئة، خدمة سريعة، وموقع استراتيجي).
   - **القائمة التفاعلية الشاملة (Menu)**:
     - شريط كبسولات بأسهم تمرير لجميع الفئات: الساخن، البارد، لاتيه، آيس تي، موهيتو، عصائر، سموزي، فرابيه، ميلك شيك، كوكتيل، إمبراطور، حلويات، وأراكيل.
     - بحث فوري بالاسم أو الوصف.
     - أسعار بالدولار الأمريكي مع زر مباشر لكل صنف يفتح محادثة واتساب جاهزة بنص الطلب واسم المشروب وسعره.
   - **العروض الحصرية (Special Offers)**: باقات توفير مع تفاصيل ومواعيد انتهاء وطلب عبر واتساب.
   - **المعرض (Gallery & Lightbox)**: شبكة صور احترافية مع عارض صور منبثق عند النقر للتكبير.
   - **موقعنا (Location & Maps)**: خريطة تفاعلية مدمجة، تفاصيل العنوان وساعات العمل وزر الاتجاهات.
   - **تواصل معنا (Contact & WhatsApp)**: معلومات الاتصال، روابط التواصل الاجتماعي، ونموذج إرسال رسالة فورية إلى واتساب.
   - **زر واتساب عائم نابض (Floating Pulsing WhatsApp)** ثابت أسفل الشاشة.

4. **السيو والأداء (SEO & Performance)**:
   - وسوم Open Graph وTwitter Cards.
   - ترميز البيانات المنظمة Schema.org بصيغة JSON-LD لـ `CafeOrCoffeeShop`.
   - تحميل كسول للصور (`loading="lazy"`).

## 🛠️ كيف تقوم بتعديل المحتوى والأسعار؟

تم فصل جميع البيانات في ملف واحد سهل التعديل: `js/data.js`:

1. **تعديل رقم واتساب المقهى ومعلومات التواصل**:
   افتح `js/data.js` وعدل المتغير في بداية الملف:
   ```javascript
   const StorvenConfig = {
       whatsappNumber: "963900000000", // ضع رقم واتساب المقهى مع الرمز الدولي بدون +
       phoneDisplay: "+963 900 000 000",
       googleMapsLink: "رابط خريطة المقهى...",
       // ...
   };
   ```

2. **إضافة أو تعديل أصناف القائمة والأسعار**:
   في مصفوفة `menuItems`:
   ```javascript
   {
       id: "hot-1",
       category: "hot", // فئة الصنف (hot, cold, latte, mojito, hookah ...)
       nameAr: "إسبريسو سينجل",
       nameEn: "Single Espresso",
       descAr: "وصف الصنف بالعربية",
       descEn: "English item description",
       price: "$1.50",
       image: "رابط صورة الصنف",
       badge: "الأكثر طلباً" // أو null
   }
   ```

3. **تعديل صور وقصص الستوريز**:
   في مصفوفة `storvenMoments` يمكنك وضع صور أو مقاطع المقهى الحقيقية.

## 🚀 كيفية تشغيل الموقع ونشره

### 1. التشغيل المحلي (Local Preview):
- افتح ملف `index.html` في أي متصفح، أو انقر عليه نقراً مزدوجاً.
- أو شغّل خادم محلي مثل `Live Server` في VS Code أو `npx serve .`.

### 2. النشر مجاناً على الإنترنت:
- **GitHub Pages**:
  1. أنشئ مستودعاً جديداً (New Repository) على GitHub وارفع الملفات إليه.
  2. اذهب إلى **Settings** > **Pages**.
  3. اختر الفرع `main` ثم احفظ، وسيعمل الموقع برابط مباشر فوري.
- **Netlify أو Vercel**:
  - اسحب مجلد المشروع مباشرة وأفلته في لوحة تحكم Netlify Drop (أو Vercel) وسينطلق الموقع في ثوانٍ مع شهادة SSL مجانية.
